# Proxmox Reverse SSH Tunnel 🚀

A secure, production-ready solution to expose local Proxmox VE and LXC containers behind NAT/firewalls via a public VPS.

## 📦 Features
- Automated systemd service management
- Secure ED25519 key authentication
- Built-in brute-force defense & hardening guide

## 🛠️ Quick Start
1. Clone or download scripts.
2. Run `bash scripts/install-tunnel.sh` on your node.
